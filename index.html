CohortLens Technical Guide & Methodology

Product Overview

CohortLens is a client-side analytics processor built specifically for SaaS founders and financial auditors. It transforms unnormalized transaction ledgers into standard N-Month cohort retention heatmaps.

Metric Methodology

  • Cohort Month: First timestamp where positive revenue is recorded for a distinct customer.
  • Month N Retention %: Distinct active customers in month N divided by initial cohort size.

Zero Cloud Data Leakage

This application operates purely inside client memory. Once the page is loaded, calculations execute offline inside your web browser.
